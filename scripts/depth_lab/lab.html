Depth parallax lab — phase 0

Same asset, same depth map, two shaders. Left is naive single-sample UV displacement. Right is ray-marched heightfield (the DepthFlow approach). Push amplitude until each one breaks.

A — naive UV displacement–

One sample. uv += cam * (depth - focus). Cheap. Smears at occlusion boundaries as amplitude rises.

B — ray-marched heightfield–

Marches the ray until it meets the depth surface, then a secant refine. Occlusion resolves instead of stretching. Costs steps texture fetches per pixel.
